# Exercício: Responsividade

1. Utilize como base o arquivo HTML disponibilizado em [./_assets/01-exercicio1-boilerplate.html](./_assets/01-exercicio1-boilerplate.html)
2. No arquivo CSS, aplique os seguintes estilos: 
    - Quando a tela tiver largura menor que 768px, os cards do menu devem ser exibidos um abaixo do outro (em coluna), com espaçamento entre eles.
    - Aumente o tamanho da fonte do título (h1) para 2rem em telas grandes (largura acima de 1024px). Reduza para 1.5rem em telas menores que 480px.
    - Diminua o padding do main para 10px em telas menores que 600px.
