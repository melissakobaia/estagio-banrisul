# Exercício: Cor, Texto e Fonte

1. Utilize como base o arquivo HTML disponibilizado em [./_assets/01-exercicio1-boilerplate.html](./_assets/01-exercicio1-boilerplate.html)
2. No arquivo CSS, aplique os seguintes estilos:
    - Defina uma cor de fundo #f0f8ff para a página e centralize todo o texto.
    - Altere a cor do texto dos títulos:
        - `<h1>` deve ter a cor #173AEB.
        - `<h2>` deve ter a cor #FC9642.
    - Aplique nos parágrafos a fonte "Arial" e defina o tamanho da fonte como 18px.
    - Destaque a palavra dentro da tag `<span>` deixando-a itálica.
