# Exercício: Seletores de Grupo, Combinados e Universal

1. Utilize como base o arquivo HTML disponibilizado em [./_assets/01-exercicio1-boilerplate.html](./_assets/01-exercicio1-boilerplate.html).
2. No CSS, defina os seguintes estilos:
   - Aplique uma margem (`margin`) um padding (`padding`) de `0` a todos os elementos.
   - Todos `<h1>` e `<h2>` devem ter o texto centralizado (`text-align`) e uma cor de texto (`color`) azul.
   - Todos os `<li>` dentro de uma `<ul>` devem ter um fundo (`background-color`) cinza.
   - Todos os `<li>` que são filhos diretos de uma `<ul>` devem ter uma cor de texto azul.
