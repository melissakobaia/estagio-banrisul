# Exercício: Espaçamento

1. Utilize como base o arquivo HTML disponibilizado em [./_assets/01-exercicio1-boilerplate.html](./_assets/01-exercicio1-boilerplate.html)
2. No arquivo CSS, aplique os seguintes estilos:
    - A div perfil deve ter:
        - Espaçamento interno: 20px
        - Espaçamento externo: 40px
        - Borda: 2px sólida azul
    - O título `<h2>` deve ter uma margem inferior de 15px
    - O último `<p>` deve ter uma margem superior de 10px
    - Todos os `<p>` devem ter espaçamento interno de 5px
