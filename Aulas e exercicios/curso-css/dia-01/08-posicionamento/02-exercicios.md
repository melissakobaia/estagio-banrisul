# Exercícios: Posicionamento e Display

## Exercício 1: Display
1. Utilize como base o arquivo HTML disponibilizado em [./_assets/01-exercicio1-boilerplate.html](./_assets/01-exercicio1-boilerplate.html)
2. No arquivo CSS, aplique os seguintes estilos:
    - Faça com que o elemento `.item-a` (que é um `<p>`, logo `block` por padrão) se comporte como um elemento inline.
    - O elemento `.item-b` é um `<span>` (`inline` por padrão). Altere-o para `inline-block`.
    - Use a propriedade `display` para fazer o elemento `.item-c` desaparecer completamente da página.
   

## Exercício 2: Position e z-index 
1. Utilize como base o arquivo HTML disponibilizado em [./_assets/02-exercicio2-boilerplate.html](./_assets/02-exercicio2-boilerplate.html) 
2. No arquivo CSS, aplique os seguintes estilos:
    - Defina o elemento `.container-position` como o ponto de referência para os filhos, usando `position: relative;`.
    - Mova a `.caixa1` (que está dentro do contêiner) 20px para baixo (top) e 30px para a direita (left) de sua posição original, usando `position: relative`;.
    - Defina a `.caixa2` para ter posição absoluta e posicione-a no canto superior direito do `.container-position`.
    - Defina a `.caixa3` para ter posição absoluta e posicione-a no canto inferior esquerdo do `.container-position`.
    - Faça com que o elemento `.menu-fixo` fique fixo no topo da janela.
    - Garanta que a `.caixa1` fique por cima de qualquer outra coisa que ela possa cobrir.
