# Exercício: Pseudo-classes e Pseudo-elementos
1. Utilize como base o arquivo HTML disponibilizado em [./_assets/01-exercicio1-boilerplate.html](./_assets/01-exercicio1-boilerplate.html).
2. No CSS, aplique os seguintes estilos:
   - Mude a cor dos links para vermelho ao passar o mouse (hover).
   - Mude a cor dos links visitados para verde.
   - Destaque o primeiro link da lista, alterando sua cor de fundo para cinza.
   - Adicione um ícone de seta (→) antes de cada link.
